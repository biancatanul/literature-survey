# Saha2020: Measuring Non-Expert Comprehension of Machine Learning Fairness Metrics

- **Type:** user study
- **Priority:** primary
- **Reference:** see `references.bib`, key `Saha2020`

## Summary

Asks whether non-experts understand basic definitions of ML fairness. The authors built a comprehension score for demographic parity, equal opportunity and equalized odds, which were explained as rules in a hiring scenario with worked examples and no notation.

## Use in my thesis

Plain-language explanations of metrics, and the design of user testing.
