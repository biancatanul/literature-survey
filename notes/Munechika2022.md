# Munechika2022: Visual Auditor: Interactive Visualization for Detection and Summarization of Model Biases

- **Type:** visualization system
- **Priority:** primary
- **Reference:** see `references.bib`, key `Munechika2022`

## Summary

Interactive visualization tool for auditing a trained ML model for biases (not datasets). Focuses on intersectional bias: it takes underperforming slices and visualizes them. The target audience is ML practitioners.

## Use in my thesis

Design reference for the model auditing extension and for how to show subgroup disparities visually.
