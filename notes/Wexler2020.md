# Wexler2020: The What-If Tool: Interactive Probing of Machine Learning Models

- **Type:** tool paper
- **Priority:** primary
- **Reference:** see `references.bib`, key `Wexler2020`

## Summary

The What-If Tool is an open-source application that lets practitioners probe, visualize and analyze ML systems with minimal coding. It needs only a trained model and a sample dataset, and runs inside TensorBoard, Jupyter and Colab. It stresses hypothetical outcomes, intersectional analysis and fairness issues.

Link: https://pair-code.github.io/what-if-tool/
