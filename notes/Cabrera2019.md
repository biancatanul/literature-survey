# Cabrera2019: FairVis: Visual Analytics for Discovering Intersectional Bias in Machine Learning

- **Type:** visualization tool
- **Priority:** primary
- **Reference:** see `references.bib`, key `Cabrera2019`

## Summary

FairVis is a mixed-initiative visual analytics system with a subgroup discovery technique for auditing the fairness of ML models. Users can generate known subgroups or explore suggested and similar ones, moving from an overview to a detailed investigation. It is aimed at data scientists auditing a classifier.

## Use in my thesis

Visualization design (subgroup comparison view).

## Gap

Works on a trained model and targets ML practitioners, while my application starts from the dataset.
